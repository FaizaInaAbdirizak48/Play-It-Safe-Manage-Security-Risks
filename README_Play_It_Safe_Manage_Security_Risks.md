## About This Repository

This repository documents my learning from Course 2 of the Google Cybersecurity Professional Certificate. It focuses on how cybersecurity professionals identify and manage risks, use security frameworks and controls, analyze SIEM data, respond to incidents, and conduct security audits.

These are my personal notes and practice activities, not official Google course materials.

## Learning Objectives

- Identify common threats, risks, and vulnerabilities that can affect business operations.
- Understand how security frameworks and controls help protect organizations.
- Learn the purpose of Security Information and Event Management (SIEM) tools.
- Understand how incident response playbooks guide security teams.
- Practice conducting a security audit.

## Course Topics

### 1. Security Domains
- Explore security domains and their role in protecting an organization.
- Understand threats, risks, and vulnerabilities.
- Review risk management concepts and the NIST Risk Management Framework (RMF).

### 2. Security Frameworks and Controls
- Understand the purpose of security frameworks and controls.
- Review the CIA triad:
  - **Confidentiality:** Protect information from unauthorized access.
  - **Integrity:** Protect information from unauthorized or improper changes.
  - **Availability:** Ensure information and systems are accessible when needed.
- Explore the NIST Cybersecurity Framework (CSF).
- Learn about OWASP security principles.
- Practice planning and conducting a security audit.

### 3. Introduction to Cybersecurity Tools
- Understand logs and SIEM tools.
- Explore SIEM dashboards.
- Learn how security analysts use SIEM tools to identify potential threats.

### 4. Use Playbooks to Respond to Incidents
- Understand the purpose of incident response playbooks.
- Learn the phases of an incident response playbook.
- Practice using a playbook to respond to threats, risks, and vulnerabilities.
